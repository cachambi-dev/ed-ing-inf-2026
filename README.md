## 🚀 Cómo Ejecutar los Trabajos Prácticos

### 1. Requisitos Previos
Asegúrate de tener instalado el Java Development Kit (JDK), versión 17 o superior. Puedes comprobar tu versión ejecutando:
```bash
java -version
```

### 2. Clonar el repositorio
```bash
git clone https://gitlab.com/ing-informatica2/ed-2026.git
cd ed-2026
```

### 3. Compilación y Ejecución por Consola
Para compilar y ejecutar cualquier punto manualmente, navega hasta la carpeta del código fuente de cada TP. Por ejemplo, para el TP0:
```bash
cd tp-0/src
javac Punto1.java
java Punto1
```

O bien, puedes abrir la carpeta raíz del proyecto directamente en tu IDE preferido para importar todos los módulos y ejecutar los archivos con un solo clic.
